Politique de confidentialité

Dernière mise à jour : 4 octobre 2026

Ce site est hébergé sur GitHub Pages. Il s'agit d'un site statique : il ne collecte aucune donnée personnelle, n'utilise aucun cookie et n'inclut aucun script de mesure d'audience ou de publicité.

Cookies

Aucun cookie n'est déposé par ce site. GitHub peut en déposer un dans le cadre du fonctionnement de la plateforme (par exemple pour l'authentification ou la mesure d'audience), sous sa propre politique de confidentialité.

Contacts

Pour toute question relative à cette politique, vous pouvez ouvrir une discussion publique sur le dépôt GitHub associé à ce site.
